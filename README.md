# NBA Player Value

An analysis of NBA players' completed-season performance relative
to their same-season salary.

## Project question

Which players delivered more or less on-court contribution than
expected for their salary in the same season?

## Scope

- Initial season: 2025–26.
- Regular-season performance.
- Season-specific salary rather than contract average annual value.
- Contract context, including rookie-scale contracts.
- Separate views of total contribution and performance when available.
- Base salary initially; earned bonuses may be incorporated later
  if reliable data is available.

## Status

In development. Currently setting up the project and validating
salary data sources.

## Environment

- Python 3.13
- Project-specific virtual environment: `.venv`

## Planned salary source

Spotrac. Salary definitions and coverage are being investigated
before data collection.
